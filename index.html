How to read an entry. Each page opens with a KPI strip, then a hierarchical BOM tree (Level 0 → systems → components, HIGH-priority nodes emphasised), a linear value-chain ladder (raw material → aftermarket, with supplier tiers), a click-through company map (click any node to see its listed companies, exposure type and evidence), and a company × node matrix. Entry identity is industry + geographic scope; the same industry analysed for a different scope gets its own page rather than overwriting this one.
